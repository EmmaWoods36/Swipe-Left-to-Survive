Amy Dress-Up Game Perplexity Split Pack
======================================

The original complete zip is about 210 MB, so this split version breaks the same asset pack into smaller upload-friendly zips.

Recommended Perplexity upload order:
1. 00_manifest_code_ready_only.zip
2. Only the asset category zips needed for the task you are asking Perplexity to help with

For code work, upload the manifest-only zip first. It contains:
- asset_manifest.csv
- asset_manifest.json
- amy_dressup_shop_data.json
- README.txt

The shop JSON is the most code-ready file. It includes:
- items grouped by category
- item IDs
- slot/category
- price in Soft Life Funds
- render layer
- asset path inside the zip
- shop visibility / owned-by-default flags

Note: Some visual assets still need QA/alignment review before production, especially any item generated before the full-canvas overlay rule was locked in.
